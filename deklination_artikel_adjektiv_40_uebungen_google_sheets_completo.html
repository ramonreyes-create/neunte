Deklination von Artikel und Adjektiv

40 Übungen mit Kontext, Kasus und Artikeltyp

Angaben der Schülerin

Bitte den Namen eingeben, bevor das Ergebnis gesendet wird.

Bild als Hilfe

Aufgabe

Arbeitsauftrag: Ergänze in jedem Satz die richtige Deklination des Artikels und des Adjektivs. Das Nomen bleibt unverändert. Der vorgegebene Adjektivstamm muss richtig dekliniert werden.

Bei jeder Aufgabe steht, ob es sich um einen bestimmten Artikel oder einen unbestimmten Artikel handelt.

Beispiel bestimmter Artikel:
Ich sehe den kleinen Hund.
Beispiel unbestimmter Artikel:
Sie kauft ein blaues Heft.
Tipp:
Frage zuerst nach dem Kasus: Wer? Wen? Wem? Wohin? Wo?

So arbeitest du: Schreibe zuerst den Artikel, dann die passende Adjektivendung. Beispiel: Vorgabe Adjektiv: klein → den + kleinen Hund.

Google-Sheets-Code für den Lehrer

Kopiere diesen Code in Erweiterungen → Apps Script deiner Google-Tabelle. Danach die Web-App-URL im HTML bei WEBAPP_URL einfügen.

// Google Apps Script
// 1. Öffne Google Sheets.
// 2. Erweiterungen → Apps Script.
// 3. Füge diesen Code ein.
// 4. Bereitstellen → Neue Bereitstellung → Web-App.
// 5. Zugriff: Jeder.
// 6. Die Web-App-URL in WEBAPP_URL im HTML einfügen.

function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const data = JSON.parse(e.postData.contents);

  if (sheet.getLastRow() === 0) {
    sheet.appendRow([
      "Name",
      "Datum",
      "Uhrzeit",
      "Übungen gemacht",
      "Richtig",
      "Versuche gesamt",
      "Erfolgsquote",
      "Details pro Übung"
    ]);
  }

  sheet.appendRow([
    data.name || "",
    data.datum || "",
    data.uhrzeit || "",
    data.uebungenGemacht || 0,
    data.richtig || 0,
    data.versucheGesamt || 0,
    data.erfolgsquote || "",
    data.details || ""
  ]);

  return ContentService
    .createTextOutput(JSON.stringify({status: "ok"}))
    .setMimeType(ContentService.MimeType.JSON);
}
